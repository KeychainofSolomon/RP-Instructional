# RP-Instructional

Skills for roleplay agents.

## npc-temperament
A number-driven NPC engine: every NPC gets a fixed temperament (from their name), station, office, drive, contradiction and quirk; each encounter rolls a weighted demeanor, with a 15–20% agency chance to break pattern. NPCs only ask for help when an Open drive passes five gates, so quests stay rare.

**Install:** download `npc-temperament.skill` and upload it under Skills in Claude's settings, or copy the `npc-temperament/` folder into your skills directory.
