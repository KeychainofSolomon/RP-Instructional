# RP-Instructional

Skills for roleplay agents.

## npc-temperament
A cause-driven, setting-neutral NPC engine. Every NPC has a fixed nature (temperament, station, office, drive, contradiction, quirk). Each encounter's mood follows from causes: the NPC's own day, how the player approaches them, trust, and, in dangerous scenes, a small chance of a danger leaning. Pattern breaks are rare (2–5%, 10% only for outliers), weirdness is 1%, and NPCs only ask for help when an Open drive passes five gates. Most asks are partial: the outsider can do one piece, and the heart of it stays theirs.

**Install:** download `npc-temperament.skill` and upload it under Skills in Claude's settings, or copy the `npc-temperament/` folder into your skills directory.
